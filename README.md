# AutoVerif-AI

AutoVerif-AI is an autonomous AI-powered RTL verification and
self-healing system.

## Objective

The system automatically:

1. Understands RTL design
2. Generates verification strategies
3. Generates testbenches
4. Runs RTL simulations
5. Analyzes simulation failures
6. Identifies probable RTL bugs
7. Proposes or generates RTL fixes
8. Re-runs verification
9. Produces verification reports

## Architecture
```
RTL
 ↓
AI Agent
 ↓
Testbench Generation
 ↓
EDA Simulation
 ↓
Result Analysis
 ↓
Bug Detection
 ↓
RTL Repair
 ↓
Re-verification
```
